Machinery in Red local operator is a private desktop tool for managing Herman Boma’s Machinery in Red YouTube channel.

What the app does

With the channel owner’s Google authorization, the tool reads channel and video information, performance analytics, and available reporting resources. It supports the channel’s research, measurement and publishing workflow.

The current client collects analytics. Its approved YouTube management permission also permits video, playlist, caption and comment changes; those operations require corresponding implemented features and owner authorization.

Built for one channel

This is an owner-operated tool, not a public service. There is no public sign-up, and visitors to this website cannot use it to access the channel. Google authorization and channel identity checks control access.

The channel publishes short, opinionated explainers about AI, software and the ideas underneath them.
